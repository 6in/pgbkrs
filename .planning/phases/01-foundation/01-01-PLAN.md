  <files>go.mod, go.sum, internal/core/interfaces.go, internal/core/types.go, internal/core/registry.go</files>
  <behavior>
    - ObjectDef is an interface with Header() returning ObjectHeader
    - TableDef, ViewDef, and all other *Def structs embed ObjectHeader and implement ObjectDef.Header()
    - SchemaFetcher.Fetch(ctx, conn, schema) returns ([]ObjectDef, error)
    - Serializer.Serialize(def) returns ([]byte, error) and Deserialize(data) returns (ObjectDef, error)
    - DDLGenerator.GenerateDDL(def) and GenerateDrop(def) both return ([]string, error)
    - NewCommandRegistry() returns a registry with all three maps initialized (non-nil)
    - Register(kind, f, s, g) stores all three; subsequent Fetcher(kind) returns the stored fetcher (not nil)
  </behavior>
  <action>
Run `go mod init github.com/pgbkrs/pgbackup` in the repo root, then `go get github.com/jackc/pgx/v5@latest go.yaml.in/yaml/v3@latest github.com/spf13/cobra@latest github.com/mattn/go-isatty@latest`.

Create `internal/core/interfaces.go` with package `core`. Define three interfaces exactly as in RESEARCH.md section "Core Interfaces":
- `SchemaFetcher` with `Fetch(ctx context.Context, conn *pgx.Conn, schema string) ([]ObjectDef, error)`
- `Serializer` with `Serialize(def ObjectDef) ([]byte, error)` and `Deserialize(data []byte) (ObjectDef, error)`
- `DDLGenerator` with `GenerateDDL(def ObjectDef) ([]string, error)` and `GenerateDrop(def ObjectDef) ([]string, error)`

Create `internal/core/types.go` with:
- `ObjectKind` as a `string` type
- Constants: `KindTable`, `KindView`, `KindMaterializedView`, `KindFunction`, `KindSequence`, `KindTrigger`, `KindType`, `KindDomain`, `KindEnum`, `KindPolicy` with values matching those names in snake_case
- `ObjectHeader` struct with fields `Kind ObjectKind`, `Schema string`, `Name string`
- `ObjectDef` interface with single method `Header() ObjectHeader`
- Concrete structs: `TableDef`, `ViewDef`, `MaterializedViewDef`, `FunctionDef`, `SequenceDef`, `TriggerDef`, `TypeDef`, `DomainDef`, `EnumDef`, `PolicyDef` — all embed `ObjectHeader`, add a `Definition string` field (except TableDef which just embeds ObjectHeader for now), and implement `Header() ObjectHeader { return d.ObjectHeader }`

Create `internal/core/registry.go` exactly as in RESEARCH.md section "CommandRegistry" — use the verbatim spec code.

Note: `internal/core` must NOT import any other `internal/` package. It imports only stdlib and `github.com/jackc/pgx/v5`.
