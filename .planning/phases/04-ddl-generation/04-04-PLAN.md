DROP patterns (from research):
```
Sequence:   DROP SEQUENCE IF EXISTS schema.name CASCADE
Type:       DROP TYPE IF EXISTS schema.name CASCADE
Domain:     DROP DOMAIN IF EXISTS schema.name CASCADE
Enum:       DROP TYPE IF EXISTS schema.name CASCADE  (enums are types in PG)
Policy:     DROP POLICY IF EXISTS name ON schema.tablename
```

    - Domain Test 1: CREATE DOMAIN schema.name AS basetype with NOT NULL, DEFAULT, and CONSTRAINT checkname CHECK (def)

1. **Sequence generator** (`internal/ddl/sequence/generator.go`):
   - Replace stub. Type-assert to `core.SequenceDef` (value receiver).
   - `GenerateDDL`: `CREATE SEQUENCE schema.name START start MINVALUE min MAXVALUE max INCREMENT BY inc CYCLE|NO CYCLE CACHE cache`
   - All attributes explicitly included (pitfall from research: PostgreSQL defaults vary by data type).
   - `GenerateDrop`: `DROP SEQUENCE IF EXISTS schema.name CASCADE`

2. **Composite type generator** (`internal/ddl/compositetype/generator.go`):
   - Replace stub. Type-assert to `core.TypeDef` (value receiver).
   - `GenerateDDL`: `CREATE TYPE schema.name AS (\n    field1 type1,\n    field2 type2\n)`
   - Join fields with commas. Last field has no trailing comma.
   - `GenerateDrop`: `DROP TYPE IF EXISTS schema.name CASCADE`

3. **Domain generator** (`internal/ddl/domain/generator.go`):
   - Replace stub. Type-assert to `core.DomainDef` (value receiver).
   - `GenerateDDL`: Build incrementally:
     - Start: `CREATE DOMAIN schema.name AS basetype`
     - If `!dd.Nullable`: append ` NOT NULL`
     - If `dd.Default != ""`: append ` DEFAULT default`
     - If `dd.CheckName != ""`: append ` CONSTRAINT checkname checkdefinition` (Definition already contains "CHECK (...)")
   - `GenerateDrop`: `DROP DOMAIN IF EXISTS schema.name CASCADE`

**Pitfalls (from research):**
- Sequence: explicitly include ALL attributes, do not rely on PostgreSQL defaults
- Domain: preserve check constraint name using CONSTRAINT keyword (pitfall 7)
