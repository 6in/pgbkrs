Create `internal/resolve/manifest.go` with:

1. **Manifest struct** with yaml tags matching spec 5.1:
   ```go
   type Manifest struct {
       BackupAt      string         `yaml:"backup_at"`
       PgVersion     string         `yaml:"pg_version"`
       ToolVersion   string         `yaml:"tool_version"`
       Snapshot      bool           `yaml:"snapshot"`
       SkippedTables []SkipEntry    `yaml:"skipped_tables"`
       Objects       []ObjectEntry  `yaml:"objects"`
       RestoreOrder  []RestoreEntry `yaml:"restore_order"`
   }
   ```

2. **SkipEntry struct:**
   ```go
   type SkipEntry struct {
       Schema string `yaml:"schema"`
       Name   string `yaml:"name"`
       Reason string `yaml:"reason"`
   }
   ```

3. **ObjectEntry struct:**
   ```go
   type ObjectEntry struct {
       ID        string   `yaml:"id"`         // "schema.name" format per spec
       Kind      string   `yaml:"kind"`
       DependsOn []string `yaml:"depends_on"` // list of "schema.name" dependency IDs
   }
   ```
   Note: DependsOn must serialize as `depends_on: []` when empty (not omitted). Use a non-pointer slice; yaml/v3 marshals nil slice as `[]` — verify this in tests. If yaml/v3 marshals nil as `depends_on: null`, initialize to `[]string{}` explicitly.

4. **RestoreEntry struct:**
   ```go
   type RestoreEntry struct {
       Schema    string `yaml:"schema"`
       Kind      string `yaml:"kind"`
       Name      string `yaml:"name"`
       FromTable string `yaml:"from_table,omitempty"` // only for FK entries
   }
   ```

5. **ManifestParams struct** — input to BuildManifest:
   ```go
   type ManifestParams struct {
       BackupAt    string          // ISO 8601 timestamp
       PgVersion   string
       ToolVersion string
       Snapshot    bool
       Skipped     []SkipEntry
   }
   ```

6. **BuildManifest(objects []core.ObjectDef, params ManifestParams) (*Manifest, error)** function:
   - Call BuildRestoreOrder(objects) to get sorted headers (includes FK at end)
   - Build DAG internally (or accept it) to extract depends_on for each object
   - Actually, BuildRestoreOrder already builds the DAG internally. To avoid rebuilding, refactor: create an internal helper that returns both the order AND the DAG. OR: build the DAG here too (it's cheap). **Chosen approach:** Build DAG here explicitly so we can read edges for depends_on. Steps:
     a. Separate FKs from others (same logic as BuildRestoreOrder)
     b. Build DAG from non-FK objects: NewDAG(), AddObject for each, Resolve()
     c. Call dag.TopologicalSort() for order
     d. Append FK headers sorted by schema.name
     e. Build Objects slice: for each non-FK object, create ObjectEntry with ID = "schema.name", Kind = string(header.Kind), DependsOn = convert DAG edges from "schema.kind.name" to "schema.name" format
     f. For FK objects, create ObjectEntry with Kind = "fk", DependsOn = [source_table "schema.name", target_table "schema.name"]
     g. Build RestoreOrder slice: for each header in order, create RestoreEntry. For FK entries, set Kind = "fk" and FromTable = ForeignKeyDef.SourceTable (need to look up the original ForeignKeyDef by header)
   - Populate SkippedTables from params.Skipped
   - Return assembled Manifest

7. **WriteManifest(path string, m *Manifest) error** function:
   - yaml.Marshal(m) then os.WriteFile with 0644 permissions
   - Straightforward
