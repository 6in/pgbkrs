   ```go
   type Manifest struct {
       BackupAt      string         `yaml:"backup_at"`
       PgVersion     string         `yaml:"pg_version"`
       ToolVersion   string         `yaml:"tool_version"`
       Snapshot      bool           `yaml:"snapshot"`
       SkippedTables []SkipEntry    `yaml:"skipped_tables"`

   }
   ```

2. **SkipEntry struct:**
   ```go
   type SkipEntry struct {
       Schema string `yaml:"schema"`
       Name   string `yaml:"name"`
       Reason string `yaml:"reason"`
   }
   ```

3. **ObjectEntry struct:**
   ```go
   type ObjectEntry struct {
       ID        string   `yaml:"id"`         // "schema.name" format per spec
       Kind      string   `yaml:"kind"`
       DependsOn []string `yaml:"depends_on"` // list of "schema.name" dependency IDs
   }
   ```
   Note: DependsOn must serialize as `depends_on: []` when empty (not omitted). Use a non-pointer slice; yaml/v3 marshals nil slice as `[]` — verify this in tests. If yaml/v3 marshals nil as `depends_on: null`, initialize to `[]string{}` explicitly.

4. **RestoreEntry struct:**
   ```go
   type RestoreEntry struct {
       Schema    string `yaml:"schema"`
       Kind      string `yaml:"kind"`
       Name      string `yaml:"name"`
       FromTable string `yaml:"from_table,omitempty"` // only for FK entries
   }
   ```

5. **ManifestParams struct** — input to BuildManifest:
   ```go
   type ManifestParams struct {
       BackupAt    string          // ISO 8601 timestamp
       PgVersion   string
       ToolVersion string
       Snapshot    bool
       Skipped     []SkipEntry
   }
   ```

6. **BuildManifest(objects []core.ObjectDef, params ManifestParams) (*Manifest, error)** function:

   **Step A — Get restore order via BuildRestoreOrder (single authoritative entry point):**
   Call `BuildRestoreOrder(objects)` from kahn.go to obtain the `[]core.ObjectHeader` restore order. This is the ONLY place that computes topological sort + FK isolation. Do NOT reimplement FK separation or Kahn's sort here.

   **Step B — Build a DAG solely to read dependency edges for objects[].depends_on:**
   Construct a separate DAG instance to extract per-object dependency information:
   - Separate FKs from non-FK objects (iterate objects, check `core.KindForeignKey`)
   - `dag := NewDAG()`
   - For each non-FK object: `dag.AddObject(obj)`
   - `dag.Resolve(nonFKObjects)` to build edges
   - For each non-FK object: read `dag.Edges(NodeID(obj.Header()))` to get dependency nodeIDs in "schema.kind.name" format, convert each to "schema.name" format (strip the kind segment) for the ObjectEntry.DependsOn field
   - For FK objects: create ObjectEntry with Kind="fk", DependsOn = [source_table "schema.name", target_table "schema.name"] derived from ForeignKeyDef fields

   **Step C — Build RestoreOrder slice from BuildRestoreOrder result:**
   For each header in the `[]core.ObjectHeader` returned by BuildRestoreOrder:
   - Create RestoreEntry with Schema, Kind (string of header.Kind), Name
   - For FK entries (Kind == KindForeignKey): set Kind="fk" and FromTable = look up the original ForeignKeyDef by matching header to find SourceTable

   **Step D — Assemble Manifest:**
   - Populate metadata from params (BackupAt, PgVersion, ToolVersion, Snapshot)
   - Set SkippedTables from params.Skipped
   - Set Objects from Step B
   - Set RestoreOrder from Step C
   - Return assembled Manifest

7. **WriteManifest(path string, m *Manifest) error** function:
   - yaml.Marshal(m) then os.WriteFile with 0644 permissions
