    The RunBackup function currently has a TODO comment for snapshot mode. Replace it with the full snapshot branch:

    ```go
    func RunBackup(ctx context.Context, conn *pgx.Conn, outDir string, snapshot bool) error {
        // ... existing: create backupRoot, fetch pgVersion, discover schemas ...

        // Determine the query connection: snapshot mode uses a transaction
        var queryConn *pgx.Conn
        var tx pgx.Tx
        if snapshot {
            var err error
            tx, err = conn.BeginTx(ctx, pgx.TxOptions{
                IsoLevel:   pgx.RepeatableRead,
                AccessMode: pgx.ReadOnly,
            })
            if err != nil {
                return fmt.Errorf("begin snapshot transaction: %w", err)
            }
            defer tx.Rollback(ctx) // safe no-op if committed
            queryConn = tx.Conn()
        } else {
            queryConn = conn
        }

        // All fetcher.Fetch calls and export.ExportTableData calls use queryConn
        // (replace conn with queryConn throughout the schema iteration loop)

        // After all schemas processed:
        if snapshot {
            if err := tx.Commit(ctx); err != nil {
                return fmt.Errorf("commit snapshot transaction: %w", err)
            }
        }

        // Build and write manifest (same as before, snapshot bool is passed in params)
    }
    ```

    Refactor the existing RunBackup to thread queryConn through: discoverSchemas(ctx, queryConn), all kf.fetcher.Fetch(ctx, queryConn, schema), export.ExportTableData(ctx, queryConn, ...).

    The discoverSchemas helper and buildChildOf must also accept and use queryConn instead of conn.

    Step B — Wire CLI in cmd/pgbackup/cmd/backup.go:

    Replace the stub with:
    ```go
    package cmd

    import (
        "github.com/pgbkrs/pgbackup/internal/backup"
        "github.com/spf13/cobra"
    )

    var (
        snapshotFlag bool
        outputDir    string
    )

    var backupCmd = &cobra.Command{
        Use:   "backup",
        Short: "Back up PostgreSQL schema and data to YAML+CSV files",
        RunE: func(cmd *cobra.Command, args []string) error {
            return backup.RunBackup(cmd.Context(), conn, outputDir, snapshotFlag)
        },
    }

    func init() {
        backupCmd.Flags().BoolVar(&snapshotFlag, "snapshot", false,
            "Use REPEATABLE READ transaction for a consistent snapshot across all reads")
        backupCmd.Flags().StringVar(&outputDir, "output", ".",
            "Directory where the timestamped backup folder will be created")
    }
    ```
