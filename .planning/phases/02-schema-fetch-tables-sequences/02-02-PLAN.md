Implementation structure — run these queries for each table:

**Step 1 — List all tables in schema:**
```sql
SELECT c.oid, c.relname AS name, c.relkind, c.relrowsecurity AS rls_enabled
FROM pg_class c
JOIN pg_namespace n ON c.relnamespace = n.oid
WHERE n.nspname = $1 AND c.relkind IN ('r', 'p')
ORDER BY c.relname
```
Scan into a local struct with fields: OID (uint32), Name (string), Relkind (string), RLSEnabled (bool).

**Step 2 — Columns for each table (per-table query, N+1 is acceptable):**
```sql
SELECT a.attname AS name,
       format_type(a.atttypid, a.atttypmod) AS type,
       NOT a.attnotnull AS nullable,
       COALESCE(pg_get_expr(d.adbin, d.adrelid), '') AS default_expr
FROM pg_attribute a
LEFT JOIN pg_attrdef d ON d.adrelid = a.attrelid AND d.adnum = a.attnum
WHERE a.attrelid = $1 AND a.attnum > 0 AND NOT a.attisdropped
ORDER BY a.attnum
```

**Step 3 — Constraints (PK, unique, check only — NOT FK):**
```sql
SELECT c.conname AS name, c.contype, pg_get_constraintdef(c.oid) AS definition
FROM pg_constraint c
WHERE c.conrelid = $1 AND c.contype IN ('p', 'u', 'c')
ORDER BY c.contype, c.conname
```
Map contype 'p' -> PrimaryKey, 'u' -> Unique slice, 'c' -> Check slice.

For PrimaryKeyDef.Columns, parse the columns from the constraint definition string (e.g., `PRIMARY KEY (id, tenant_id)`). Extract column names between the parentheses by splitting on comma and trimming whitespace. Do NOT query pg_attribute again — parse the pg_get_constraintdef output.

**Step 4 — Indexes (excluding constraint-backing indexes):**
```sql
SELECT ic.relname AS name, am.amname AS method, pg_get_indexdef(ix.indexrelid) AS definition
FROM pg_index ix
JOIN pg_class ic ON ix.indexrelid = ic.oid
JOIN pg_am am ON ic.relam = am.oid
WHERE ix.indrelid = $1
  AND NOT ix.indisprimary
  AND NOT EXISTS (
      SELECT 1 FROM pg_constraint con
      WHERE con.conindid = ix.indexrelid AND con.contype IN ('p', 'u')
  )
ORDER BY ic.relname
```

**Step 5 — Partition info (only for relkind='p' tables):**
```sql
-- Step 5a: strategy
SELECT pt.partstrat FROM pg_partitioned_table pt WHERE pt.partrelid = $1
-- Step 5b: children
SELECT child.relname FROM pg_inherits inh
JOIN pg_class child ON child.oid = inh.inhrelid
WHERE inh.inhparent = $1 ORDER BY child.relname
```
Map partstrat: 'r'->"range", 'l'->"list", 'h'->"hash".

Assemble each table into `core.TableDef` with:
- ObjectHeader: Kind=core.KindTable, Schema=schema, Name=table.Name
- RLS: core.RLSDef{Enabled: table.RLSEnabled}
- Partitioning: nil for relkind='r'; populated PartitionDef for relkind='p'

Add compile-time interface check at package level:

