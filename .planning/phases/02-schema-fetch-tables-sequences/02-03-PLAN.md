Create `internal/fetch/sequence/fetcher.go` with package `sequence`.

Use `pg_sequences` system view (not `pg_sequence` catalog table — the view includes `last_value` and `is_called`):

```sql
SELECT
    s.sequencename  AS name,
    s.start_value,
    s.min_value,
    s.max_value,
    s.increment_by,
    s.cycle,
    s.cache_size     AS cache,
    COALESCE(s.last_value, s.start_value - s.increment_by) AS last_value,
    s.last_value IS NOT NULL AS is_called
FROM pg_sequences s
WHERE s.schemaname = $1
ORDER BY s.sequencename
```

Note: `pg_sequences.last_value` is NULL when the sequence has never been called. Use COALESCE to handle that. `is_called` = true when last_value is not null.

Map to `core.SequenceDef`:
- ObjectHeader: Kind=core.KindSequence, Schema=schema, Name=row.Name
- StartValue, MinValue, MaxValue, IncrementBy, Cycle, Cache from view columns
- LastValue from coalesced last_value
- IsCalled from null check

Create `internal/fetch/enum/fetcher.go` with package `enum`.

Use the query from RESEARCH.md "Query: ENUM Labels for All ENUMs in a Schema":

```sql
SELECT
    t.oid,
    t.typname AS name,
    array_agg(e.enumlabel ORDER BY e.enumsortorder) AS labels
FROM pg_type t
JOIN pg_namespace n ON t.typnamespace = n.oid
JOIN pg_enum e ON e.enumtypid = t.oid
WHERE t.typtype = 'e'
  AND n.nspname = $1
GROUP BY t.oid, t.typname
ORDER BY t.typname
```

For scanning `array_agg(...)` as `[]string` in pgx v5: scan into `[]string` directly — pgx v5 handles PostgreSQL text arrays natively. Alternatively scan into `pgtype.Array[string]`.
